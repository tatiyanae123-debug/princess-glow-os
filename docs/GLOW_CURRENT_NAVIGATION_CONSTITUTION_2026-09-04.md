# GLOW OS — FUTURE NAVIGATION SYSTEM CONSTITUTION

## THE GLOW CURRENT

**Status:** CANONICAL · AUTHORITATIVE · PERMANENT

**Date locked:** 2026-09-04

This document supersedes any earlier Glow OS navigation specification that treats navigation primarily as tabs, a sidebar, a bottom bar, page replacement, a dashboard category grid, breadcrumbs, a hamburger menu, app icons, a radial menu, or separate-page switching.

The governing law is:

> Glow OS should not have navigation sitting on top of the world. Navigation should be a behavior of the world itself.

Glow OS is one continuous intelligent living world. Today, Plan, Life, Brain, and Create are major gravitational regions inside that world. The user should feel that they moved somewhere, not that they opened another page.

---

## 1. Core navigation philosophy

Glow Current is the universal movement physics underneath Glow OS. It is not a menu, toolbar, or permanently visible control layer. It connects rooms, worlds, objects, routines, projects, memories, people, places, knowledge, systems, time, conversations, and Shakti.

Glow Current combines space, intention, light, memory, gravity, depth, proximity, movement, context, and intelligence.

Navigation means the environment reorganizes around what the user is moving toward. A normal movement should:

1. sense intended destination,
2. expose its relationship to current context,
3. reveal a route,
4. preview what lies ahead,
5. carry active context forward,
6. transform toward the destination,
7. complete the movement only after commitment.

No default hard teleportation. No default page replacement.

---

Glow Current progressively replaces conventional primary navigation, including:

- Today / Plan / Life / Brain / Create tabs,

- giant navigation screens,
- breadcrumb trails,

- five floating circles used as disguised tabs,

- sci-fi HUD navigation,
- game-map navigation,
- neon pathways,
- generic glassmorphism navigation.

These may exist only as accessibility or technical fallbacks. They do not define the primary experience.

---

## 3. Glow geography

### Today
The immediate present. Current activity, what happens now, what comes next, today’s routines, commitments, and active life. Navigation is close, immediate, and temporal.

### Plan
The future. Later today, tomorrow, weeks, months, seasons, goals, projects, possibilities, and scheduled commitments. Time extends outward as depth.

### Life
The inhabited world. Beauty, skincare, hair, fitness, food, money, home, fashion, relationships, health, routines, shopping, possessions, maintenance, and places. Life is spatial, material, and connected to the physical world.

### Brain
The internal world. Memory, knowledge, observations, ideas, notes, connections, learning, questions, patterns, and reflections. Connection is the architecture rather than folders.

### Create
The generative world. Designing, writing, making, building, imagining, experimenting, drafts, references, versions, and projects. It is open, transformable, unfinished, and possibility-rich.

The five regions must eventually be recognizable by behavior and climate even before labels appear.

---

## 4. Primary interaction grammar

The canonical interaction begins:

**PRESS → REVEAL → PULL → TRAVEL**

Press and hold an unoccupied area. Material tension develops. Nearby surfaces respond. Light shifts. Refraction changes. Depth opens. Shakti responds. Relationships become perceptible.

Glow Current is mostly invisible when not needed. The user sees their world, not navigation machinery.

---

## 5. Navigation Field

When Glow Current activates, the room reveals part of the surrounding navigation field. It does not show a sitemap. It reveals relationships through depth, light pressure, material displacement, refraction, spatial openings, environmental previews, stronger object presence, and subtle gravitational pull.

Navigation Field communicates what is close, connected, deeper, and farther away.

---

## 6. Semantic proximity

Navigation is organized by meaning rather than only hierarchy.

### Near
Directly related to the current activity. Requires almost no travel.

### Mid
Related systems. Connected, but not immediately central.

### Far
Major Glow geography such as Today, Plan, Life, Brain, and Create.

Urgency may temporarily increase proximity without creating panic.

---

## 7. Depth is information architecture

- **Surface:** what matters now.
- **Near depth:** immediate related information.
- **Middle depth:** larger system context.
- **Far depth:** broader worlds, longer time horizons, and distant systems.

Distance carries meaning.

---

## 8. Seven canonical movements

### Focus
Move closer. Means: this matters right now.

### Reveal
Expose information already inside, behind, beneath, or around the current object.

### Drift
Move laterally toward a nearby related environment.

### Transform
Allow the current environment to become another environment while preserving continuity.

### Orbit
Inspect related information without leaving the current center.

### Dive
Move deeper into the same concept.

### Surface
Move outward toward broader context. Surface is the inverse of Dive.

Movement has momentum. Small movement reveals nearby information. Longer movement travels farther. Deliberate movement supports exploration. Fast intentional movement supports speed. Reduced Motion must preserve the same meaning with less displacement.

---

## 9. Magnetic intention and destination previews

As the user begins moving toward a destination, Glow may make it subtly magnetic by increasing clarity, edge light, physical presence, and route strength.

The destination should preview before commitment. The current room does not disappear. The user can release toward the destination to complete movement or reverse to cancel.

Major movement must have a commitment threshold to prevent accidental travel.

---

## 10. Glow Thread

Glow Thread is the remembered traveled path. It replaces primary breadcrumb navigation.

Glow Thread may remember:

- where the user came from,
- unfinished work,
- important previous states,
- conversation context,
- routine progression,
- temporary navigation corridors,
- preserved working states.

Recent environments can appear as miniature living contexts when requested.

---

## 11. Reverse the Current

A permanent Back button is not the primary return system.

- short backward pull: previous context,
- longer backward pull: more traveled path,
- deeper hold: recent preserved contexts.

Meaningful navigation should be reversible whenever practical.

---

## 12. Return Anchor

Return Anchor is the stable route toward the immediate present. It is not a conventional Home button. It appears as a small, recognizable physical phenomenon associated with the present moment.

Activating it brings Glow gently toward Today.

The separate **Glow OS wordmark** may still return to the central Glow OS Home/orientation environment. Home and Return Anchor have different purposes:

- **Glow OS wordmark:** central Glow OS geography.
- **Return Anchor:** immediate present / Today.

---

## 13. World Fold

World Fold provides fast long-distance orientation and travel.

The current environment recedes but remains alive. Larger Glow geography becomes visible around it. The user understands: “I am here inside a larger world.”

World Fold must never become five ordinary buttons. Today, Plan, Life, Brain, and Create must appear as environmental previews with distinct climates and spatial behavior.

---

## 14. Shakti navigation role

Shakti is not a navigation icon. Shakti influences Glow Current as intelligence inside the world.

Shakti may strengthen:

- relevant routes,
- recent places,
- unfinished work,
- contextual destinations,
- likely next steps,
- time-sensitive locations,
- relationships between information.

Shakti should guide through phenomena. Instead of telling the user “Go to Plan,” Plan’s current may become stronger.

---

## 15. Temporary Currents

Shakti may create temporary routes for a specific intention.

Examples:

- “Where was that thing about my birthday?”
- “Take me to my skincare.”
- “Show me my week.”
- “Where did I save that hair?”
- “Go back to what I was doing yesterday.”

Temporary Currents dissolve after serving their purpose.

---

## 16. Search becomes travel

Search increasingly reveals locations and relationships rather than a wall of results.

A search for one object may reveal its product, routine use, inventory, prescription information, usage history, progress observations, and related notes, with distance reflecting relevance.

Advanced users may use direct travel through Shakti, voice, keyboard, command input, or accessible text navigation.

---

## 17. Objects are doorways

Anything meaningful can become a doorway to related information.

Products connect to routine use, inventory, purchase history, instructions, progress, notes, and replacement timing.

People connect to memories, plans, relationship context, events, notes, and messages.

Dates connect to schedule, tasks, spending, habits, memories, notes, and photos.

Tasks connect to project, source, schedule, notes, history, and dependencies.

Navigation follows relationships rather than folder ownership.

---

## 18. Living Doors

Navigation should emerge from objects already inside rooms.

Examples:

- mirror → skincare progress,
- timeline → Plan,
- drawer → inventory,
- photograph → memory,
- product → information volume,
- paper → project,
- reflection → related routine,
- transparent surface → deeper context.

Do not fill rooms with glowing portal buttons.

---

## 19. Region-specific navigation laws

### Today
Current activity stays closest. Upcoming activity extends ahead. Completed activity recedes behind. Forward movement travels through the day and can gradually become Plan.

### Plan
Time is depth. Day → Week → Month → Season → Year → Long-range future.

### Life
Systems sit near one another by real-world relationship. It should feel inhabited rather than categorical.

### Brain
Relational gravity. Stronger conceptual connection produces stronger spatial relationship.

### Create
Projects are environments. Ideas branch. References orbit active work. Versions can exist behind one another. Thoughts can become projects without leaving the world.

---

## 20. Meaningful transitions

Transitions communicate why two places relate.

- Today → Plan: present stretches into future.
- Today → Brain: immediate world deepens and becomes associative.
- Life → Create: physical systems loosen into possibility.
- Brain → Create: ideas become material.
- Today → Life: current activity expands into the system supporting it.

Transitions teach Glow geography.

## 21. Generative navigation

Glow may create temporary cross-system paths that did not exist beforehand.

Example birthday path:

Birthday → Outfit → Budget → Restaurant → Calendar.

Glow may temporarily connect Plan + Fashion + Money + Places + Today. The user navigates the birthday, not database ownership.

## 22. Context-aware navigation

Current activity changes what becomes near.

Getting ready may bring weather, clothing, beauty, time, calendar, and commute closer.

Planning the week may bring calendar, goals, routines, appointments, projects, and tasks closer.

Shopping may bring inventory, wishlist, budget, replacement timing, product history, and routines closer.

Working out may bring workout, Spotify, form, timer, progress, and recovery closer.

The world reorganizes around intention.

---

## 23. Personalization without chaos

Glow may learn frequent paths, likely next actions, recently visited places, unfinished journeys, recurring routines, and contextual relationships.

Glow may personalize route strength, suggestions, Shakti guidance, destination emphasis, shortcuts, Orbit contents, and navigation predictions.

Foundational geography must remain stable. Intelligence may strengthen paths but must not randomly relocate core systems.

---

## 24. Unfinished and active work

Unfinished work remains alive as suspended fragments, faint currents, living minimized objects, retained environments, or Glow Thread states.

Active work must survive movement. Writing, planning, comparing, music, routines, instructions, and Shakti conversations may travel, shrink, float, remain docked, become Orbit objects, or remain attached through Glow Thread.

Moving does not mean losing state.

---

## 25. Navigation Continuity Layer

Every movement preserves:

1. **Positional continuity** — the user understands where they went.
2. **Contextual continuity** — relevant active information moves with them.
3. **Conversational continuity** — Shakti remembers the conversation and goal.

These are mandatory.

---

## 26. Navigation receipts

Meaningful intelligent movement may briefly show a small, temporary, clear, undoable receipt explaining what changed.

Receipts are confidence signals, not permanent chrome.

## 27. Orientation law

Glow must always quietly answer:

- Where am I?
- Where did I come from?
- What is nearby?
- What is deeper?
- Where can I go?

Environment, depth, lighting, material, movement, proximity, Glow Thread, Return Anchor, and Shakti should answer these questions before giant labels do.

Temporary room labels may appear and fade. Accessibility settings may keep them visible.

## 32. Input laws

### Touch
Hold, press, pull, pinch, drift, drag, reverse, Dive, Orbit. Gestures must remain learnable.

### Apple Pencil
Hover preview, current tracing, precision pulls, circling an object to Orbit, object pointing.

### Trackpad
Drag, hover, pinch, momentum, depth scrolling, Orbit, World Fold.

### Mouse
Cursor proximity, hover refraction, click-drag travel, scroll depth, contextual reveal.

### Keyboard
Direct destination commands, power shortcuts, accessibility navigation, fast return, navigation history, command input. Keyboard is powerful but not the dominant visible model.

### Voice
Natural language becomes movement. Shakti interprets “Take me there,” “Go back,” “Show me what is related,” “Bring up my week,” and “Take this into Create.”

---

## 33. Device laws

### iPhone
Prioritize one-hand accessibility, thumb-scale movement, hold, pull, Shakti, object interaction, contextual currents, short travel distances, and accessible World Fold. Never add five-icon bottom tabs merely because the screen is small.

### iPad
Expose more geography simultaneously. Support multitouch, Pencil hover, deeper Orbit, larger destination previews, and stronger World Fold. Pinch outward may reveal World Fold; pinch inward may support Dive.

### Desktop
Do not revert to a conventional productivity sidebar. Use hover, cursor proximity, drag, scroll depth, trackpad gestures, spatial previews, contextual objects, and keyboard acceleration.

Glow Current is device-independent physics.

---

## 34. Accessibility and Reduced Motion

Glow Current must remain usable when gestures, animation, or depth are difficult.

Optional accessibility layers may include permanent room names, stronger contrast, simplified navigation, explicit arrows, text navigation, visible history, keyboard navigation, screen-reader hierarchy, larger targets, dyslexia-friendly labels, clearer spatial indicators, and conventional fallback navigation when required.

Reduced Motion translates movement into lower-motion equivalents such as controlled layer change, depth indicators, and fading relationships. It does not remove the navigation grammar.

---

## 35. Discoverability and muscle memory

Early use may show Shakti guidance, temporary gesture hints, current demonstrations, destination previews, temporary labels, and responsive material cues. These should recede as familiarity grows.

The end state is subconscious fluency: deeper feels like deeper, reverse feels like return, World Fold feels like broader geography, Orbit feels like inspect-without-leaving, and forward feels like progress toward the relevant direction.

---

## 36. Safety, reversibility, and stability

Major movement must preview clearly before commitment. Users must be able to cancel by reversing direction.

Exploration should feel safe through pull-back, Reverse the Current, receipt Undo, Glow Thread return, Return Anchor, and temporary-state preservation.

Glow Current is intelligent. Glow geography is stable.

---

## 37. Cross-device continuity

Moving between iPhone, iPad, and desktop must preserve conceptual geography. The physical expression adapts, but Focus remains Focus, Orbit remains Orbit, Dive remains Dive, and World Fold remains the broader geography view.

---

## 38. Page difference law

Shared navigation physics must not make every page look identical.

Glow Current is shared physics. Each room decides how those laws manifest physically.

Harmony and room identity must coexist.

# Permanent constitutional rule

Every current and future Glow OS environment belongs to Glow Current.

Every room must have a location, arrival, departure, neighbors, depth, connections, local movement, deep movement, world movement, Orbit possibilities, Glow Thread continuity, Return behavior, Shakti behavior, unique environmental navigation expression, and continuity with the rest of Glow OS.

No room exists as an isolated screen.

No future page quietly invents unrelated navigation.

No conventional navigation pattern becomes the primary default simply because it is familiar.

## Final principle

**Glow OS is not a collection of pages. Glow OS is one continuous, navigable living world. Glow Current is how the user moves through it. The user moves through meaning, relationships, time, objects, memory, and intention while Glow OS continuously reorganizes around them without breaking context.**

---

## Current implementation contract

The canonical implementation now begins with these active behaviors:

- press-and-hold empty space reveals Navigation Field,
- pull upward from the revealed field opens World Fold,
- pull backward reverses recent context,
- pull forward moves through Today,
- Return Anchor brings the user toward the present,
- Glow Thread exposes recent living contexts,
- World Fold preserves the current room while showing major geography,
- Glow OS wordmark returns to the central Home geography,
- conventional Today side rail and persistent previous/next footer are retired as primary navigation,
- room-to-room Today movement remains in-place through shared URL state and material transformation,
- Shakti continues to carry context and can initiate meaningful travel,
- labels and gesture hints remain available as discoverability/accessibility layers,
- Reduced Motion preserves meaning while reducing displacement,
- major regions not yet rebuilt must not route the user into old mismatched layouts merely to satisfy a click.

This implementation is the foundation, not the final ceiling. Every new room must extend the same physics rather than adding another menu system.
