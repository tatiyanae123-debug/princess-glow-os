# Pasted markdown.md — Locked Glow OS Source Material

## Permanent source rule

`Pasted markdown.md` is an authoritative user source for Glow OS content, features, routines, logic, architecture, guardrails, tracking fields, and cross-links. It must remain represented in future Glow work even when individual rooms receive newer approved visual references.

The file is a content/behavior source, not permission to turn every room into the same list, database, dashboard, or card grid. The current continuous-world constitution and each approved room reference remain visually authoritative.

Future source batches from the same file must be routed into the correct Today / Plan / Life / Brain / Create region and the correct specialized room. Preserve provenance, source claims vs verified facts, and user-specific guardrails.

## Implementation law

When implementing information from `Pasted markdown.md`:

1. Preserve the detail and intent of the source.
2. Do not invent missing source facts and label them source-derived.
3. Keep conflicting source variants visible until a deliberate personal rule resolves them.
4. Use the room's own spatial metaphor and interaction model.
5. Never override the locked reference image with a generic UI template.
6. Let Glow connect the source across rooms rather than duplicating the same content everywhere.
7. Safety-sensitive claims remain source claims until appropriately verified.
8. Capacity, accessibility, privacy, reduced-motion and user-controlled intensity rules still apply.

The source and the visual constitution are complementary: source material determines what Glow knows and can help with; the room/reference system determines how that information physically lives and behaves in Glow OS.
