# Glow OS — Global Home Reachability Law

**Status:** CANONICAL · AUTHORITATIVE · PERMANENT

This law applies to every current Glow OS page and every page, room, world, modal environment, contextual surface, and feature created in the future.

## Permanent rule

**Glow OS = Home, and Home must always be reachable from the user's current viewport.**

A user must never have to scroll all the way back to the top of a long page just to find Home.

## Required behavior

1. If a room has a visible Glow OS wordmark or other approved Home control in the current viewport, use that control.
2. If that local Home control scrolls out of view, a small fixed Glow OS Home anchor automatically appears.
3. If a page has no local Home control at all, the fixed Glow OS Home anchor appears automatically.
4. The fixed anchor routes only to the true current `/home` environment, never the retired dashboard generation.
5. Home itself does not show a redundant Home control.
6. Authentication screens remain a special case so their authorization flow is not obscured.

## Top-position law

Every newly opened Glow destination must begin at its intended top/orientation state.

A destination must not inherit a previous room's scroll position.

This applies to:

- page-to-page movement,
- Today room changes,
- Focus,
- People,
- Places,
- Resources,
- Journey,
- temporal environments,
- future Glow Current destinations,
- contextual rooms added later.

The user should immediately see the destination's orientation, Glow OS Home access, Today access when relevant, and Ask Glow access when relevant.

## Future-page inheritance

No future page is considered complete unless:

- Home is reachable without scrolling to hunt for it,
- the page opens at the correct top position,
- a local Home control or the automatic global fallback is visible,
- Home routes to `/home`,
- navigation does not preserve an unrelated previous page's scroll offset.

This requirement is supplied from the root Glow OS architecture so future pages inherit it automatically rather than relying on manual page-by-page implementation.
