# Glow Navigation — Receding Presence Law

**Status:** CANONICAL · AUTHORITATIVE · PERMANENT

This law extends the Glow Current Effortless Interaction Law for every current and future Glow OS surface.

## Governing rule

Navigation must be **available without permanently occupying the room**.

Glow OS navigation should feel like a transparent presence that appears when needed and recedes when attention returns to the content.

## Visual behavior

- Navigation uses substantially more transparent Glow Matter than the room itself.
- It must not read as a thick opaque header placed on top of the experience.
- Shadows, borders, blur, and fills remain restrained.
- The room must remain visually legible through and around navigation.
- Navigation may condense into a smaller floating strip instead of spanning the full viewport.

## Idle behavior

When the user is not interacting with navigation, it should automatically recede after a short idle period.

Receded means the navigation no longer blocks or visually competes with the top of the room.

It may leave only an extremely subtle edge glint or invisible reveal zone so the controls remain recoverable.

## Reveal behavior

Navigation returns immediately when the user:

- moves toward the top edge,
- taps the top-edge reveal area,
- scrolls upward,
- tabs into navigation with a keyboard,
- invokes a navigation shortcut,
- opens Ask Glow,
- or otherwise begins interacting with navigation.

Ask Glow or another open navigation panel pins navigation in its visible state until the interaction ends.

## Accessibility

Auto-receding navigation must never make Home, Today, or Ask Glow unreachable.

Keyboard focus must reveal the controls before interaction.

Touch devices must have a reliable top-edge reveal target.

Reduced-motion settings may remove the slide animation, but the visible/receded state change remains.

## Permanent future-page rule

Every current and future Glow OS room must pass this test:

> Can the user see the full top of the room without permanent navigation covering it, while still being able to recover navigation instantly without learning a gesture system?

If not, the navigation is too visually heavy or too difficult to recover.

## Final standard

**Available, not constantly visible.**

**Transparent, not opaque.**

**Recedes when idle.**

**Returns instantly when needed.**
