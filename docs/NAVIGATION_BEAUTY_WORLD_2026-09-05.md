# Glow OS Navigation Update — Beauty in Both Navigation Systems

Locked Sept. 5, 2026.

Beauty is now a first-class Glow OS destination in **both** navigation systems:

1. **Primary world navigation** must include: Today · Plan · Life · Brain · Create · Beauty.
2. **Inner World / Life navigation** must also expose Beauty as a connected destination.

Beauty is not removed from Inner World when it becomes a top-level destination. Both routes resolve into the same Beauty system and preserve state/continuity.

## Beauty world architecture

Beauty is a connected region containing at minimum:

- Beauty Home / Command Center
- Makeup
- Skincare · Treatment Lab
- Wash Up / Getting Ready hygiene flow
- Facial Massage / Gua Sha Studio
- Hair
- Body Care
- Fragrance
- Nails / grooming where applicable
- Devices + Tools
- Beauty Inventory
- Treatments / Prescriptions / Provider Care
- Progress / photos / history
- Travel Beauty

Closet and Fashion remain closely connected Life/Style systems and may also be surfaced from Beauty where useful, but they are not collapsed into Skincare.

## Routing law

- Primary `Beauty` destination opens the Beauty region.
- Inner World `Beauty` threshold opens that same Beauty region.
- Beauty sub-destinations use one shared data model, not duplicated copies.
- Skincare always resolves to the inventory-driven Treatment Lab.
- Repeated access paths must preserve the same saved state, product inventory, routines, history, and Glow intelligence.

## Visual/navigation requirement

When the compact world control is visible, Beauty must appear alongside Today, Plan, Life, Brain, and Create. It must not require the user to know that Beauty lives under Life in order to reach it.
