# Princess Glow OS

Princess Glow OS is a luxury life operating system for planning, routines, habits, beauty, wellness, goals, tasks, and personal organization. The current Phase 1 experience focuses on a polished, mobile-first dashboard with a shared navigation shell and dedicated views for the core life areas.

## What’s included

- A refined Today dashboard with highlights, wellness, beauty, and ritual notes
- Shared app navigation for the full Life OS experience
- Route-based pages for Calendar, Tasks, Habits, Routines, Goals, Wellness, Beauty, Work, Money, Notes, and Settings
- A Next.js + TypeScript + Tailwind implementation designed for continued AI-driven expansion

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS
- lucide-react

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the app.

## Build

```bash
npm run build
```
